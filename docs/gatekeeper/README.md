## 当前状态

**已定**

- 行业：广电，场景：融媒体中心（不限行政层级）
- 业务本体：稿件生产（上级通稿 → 播报稿 + 短视频文案）
- 内核是因果不是并列：AI 提速 → 审核成瓶颈 → 监控让审核跟上生产速度
- 治理双向：入口准入闸（非法输入不给调用模型）+ 输出预检
- 口径：主动承认审校有方正、黑马；我们的差异在**句级来源标记**与 **AI 参与度**

## 措辞纪律

- **不说「安全」**——会被听成内容安全（易盾/天御那个红海），而且是防御性的。广电要的是**敢发、发得快、出了事说得清**。
- **不说「敏感词过滤」**——九十年代的技术印象。入口那层叫**「入口准入」**，判定的不是词，是这次调用该不该发生。
- **不说 AuditGate**——英文、技术词，对这个评委席先天弱一档。代码目录 `audit-gate/` 保持不动，赛后再改。
- **不假装审校是空白**——方正智能审校 21 类 136 个词库，黑马校对卖了三十年。主动承认，再讲我们看得见而它们看不见的那一面。
