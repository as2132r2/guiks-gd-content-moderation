# 把关人 · 试用手册

> ⚠️ 试用环境里的稿件、人名、地名、数字**全部是模拟脱敏素材**，不对应任何真实机构或个人。

拿着这份手册，你可以在十来分钟内把整条链路走一遍。不需要看代码，也不需要装任何东西。

**不知道从哪下手？** 第七节备好了六份可以直接粘贴的模拟通稿。

---

## 一、这是什么

**AI 把稿子写快十倍，审核跟不上就等于没提速。**

把关人把三审三校里**机械的校对自动化、判断留给人、每一步留痕**，让 AI 写的稿子敢发出去。

一条六步主链：

```
素材入口 → 入口准入 → 稿件生成 → 输出预检 → 三审三校 → AI 参与度追溯
```

## 三、十来分钟走一遍（推荐路径）

用 `zhangmin` 登录，进 `/workbench`。左栏已经有 15 篇稿件：**上面 7 篇是给你练手的**，下面 8 篇是铺在过去几天的本底数据，用来让监控看板有分布可看，不用管它们。

### 第 1 步 · 看入口准入的三档（2 分钟）

在生成之前，系统先判定**这次调用该不该发生**。判的不是词，是这次调用。

依次点开这三篇，看中间那张卡：

| 点开 | 你会看到 |
| --- | --- |
| **国道210线塌方抢通情况通报** | 🟡 **要理由**。涉敏感题材，但这是正当报道——系统不拦，要一个选题依据。试着在框里填一句「已获授权发布」，点放行 |
| **帮我写点东西** | 🔴 **硬拦**。屏幕上会打出 `模型调用 0 次 / 0 tokens / 无内容产生`。这一档模型完全没被碰到 |
| **写篇小说** | 🟢 **仅留痕**，但另标了「非业务用途」。不违法所以不拦，但不是新闻业务，进使用情况报表 |

> **中间那一档是最值钱的。** 编辑的日常工作就是处理敏感题材——事故通报、涉诉纠纷。
> 一刀切拦掉，系统当场就没法用了。

### 第 2 步 · 自己投一份稿（2 分钟）

点 **「＋ 新建稿件」** → **「填入示例通稿」**（一键填好，不用打字）→ **「提交入口准入」**。

它会落到「仅留痕放行」，然后点 **「生成播报稿与短视频文案」**。

看右栏：现在是 **AI 参与度 100%**，每一句都记着是谁写的。

### 第 3 步 · 看预检标出什么（2 分钟）

点 **「运行输出预检」**。三处会被标出来：

| 标注 | 动作 |
| --- | --- |
| 禁用词「隆重召开」 | 🔴 拦下——新华社规范，一般性会议不冠以「隆重」 |
| 「总投资 3.6 亿元」 | 🟡 标红——**原通稿里是 3.2 亿**。生成稿里有而原文没有的数字一律标红 |
| AI 生成内容标识 | ✅ 已按《标识办法》自动补上 |

> 预检的产出是**标注**，不是闸门。人少，阻断就是卡死，卡死就是弃用。

### 第 4 步 · 改一句，看数字跳 ⭐（1 分钟）

**这一步是整个产品最值得看的地方。**

点播报稿的 **「改稿」**，把第二句里的 **「隆重召开」改成「召开」**、**「亲自出席」改成「出席」**，保存。

看右栏的 AI 参与度——**它当场从 100% 掉下来**，并显示落差「↓ ...（人改过了）」。

同时禁用词那条标注消失了。

> 这个数字不是自己填的。**系统逐句比对上一版自动判定哪几句被人改过**——
> 被考核的人不能是这个数字的来源，否则它什么也测不到。

### 第 5 步 · 走三审三校（2 分钟）

点「提交初审」，然后依次：**初审通过 → 复审通过 → 签发**。

用右上角的**身份切换器**换角色。每一级的卡片上写着这一级该看什么：

- 初审 + 一校：错别字、语病、标点、格式
- 复审 + 二校：数据、人名、职务、地名、术语
- 终审 + 三校：导向、事实判断、通读

想试试**退回**：在复审那一步点「退回复核修改」，必须写理由才退得回去。
退回后要**真的改过一句**才能重新预检——空手走回去不算复核修改。

### 第 6 步 · 追溯与对照组（1 分钟）

签发后自动落到第 ⑥ 屏：

- **签发卡** —— 谁签的、什么时候、**签发时的 AI 参与度是多少**
- **AI 参与度折线** —— 哪一步是谁把它推低的
- **句级来源图谱** —— 每一格是一句话，颜色是它的来源
- **责任链** —— 谁在哪一级放行的

> 签发时如果还是 100%，说明这一路没人真改过——**这个数字能暴露走过场的审核**。

最后点 **「对照组：关掉把关人会怎样」**：

同一份通稿，关掉把关人 → **问题直接播出去，不知道哪句是 AI 写的，出事查不到人**。

### 第 7 步 · 看全局态势（1 分钟）

前六步看的是**一篇稿子怎么走的**，监控看板看的是**这个台最近在怎么写稿**——两件事。

点工作台顶栏右上角的**「全流程监控」**（`/monitor`，五个账号都进得去；`stationadmin` 只看不批，拿它看这一屏最顺手）。试用环境里已经有 15 篇稿件铺在过去七天，所以每一栏都有分布可看：

| 看板上的栏目 | 它回答什么 | 试用环境里大概是什么样 |
| --- | --- | --- |
| **按日趋势** | 每天出了多少稿，**签发时的 AI 参与度是多少** | 七个点，签发时 AI 参与度在 90%～100% 之间起伏 |
| **内容生产者** | 谁写的、谁改的、谁审的、谁退的 | 四个人。**按人归并，不按角色**——张敏一人多岗也只算一个人 |
| **各级审核与退回率** | 哪一级在真正把关 | 复审那一级退回率非零，其余为 0 |
| **入口准入三档** | 拦了几次、要了几次理由、放行留痕几次 | 三档都有。**要理由那一档里有走到签发的**——敏感题材不是死路 |
| **规则命中排行** | 最常犯的是哪一类错 | 一致性比对最多，其次是 AI 标识 |
| **报道方向** | 这个台在报什么 | 六个方向都有 |
| **句级来源构成** | 全台的句子里，AI 写了多少、人改了多少 | 一百多句，人改过的是少数 |

> **签发时的 AI 参与度这条线是这块看板真正的用处。** 它一直贴着 100% 不动，
> 说明这一路没人真改过——**这个数字能暴露走过场的审核**，而这是任何内容审核
> API 都看不到的，因为它们只看得见成品。

看板底部有一栏叫**「这一版还没有的」**，明写着哪些数还不可信（比如环节停留时长——试用环境里的流转是连点出来的，不代表真实工时）。**主动说明，比被问出来强。**

## 五、常见问题

**这是真的还是演的？**
素材是模拟脱敏的，这一点写在界面上。系统是真的——你看到的每个数字都能指回留痕，对照组那一屏不是重跑模拟，是同一份产物减去把关之后剩下的东西。

**为什么不用现成的内容审核 API？**
它只看得见成品，看不见生产过程，给不出 AI 参与度。

**私有化部署不就行了？**
私有化解决「模型在哪」，解决不了「模型被谁怎么用、哪句话是它写的、谁放行的」。

**词表比得过方正吗？**
比不过，也不打算比。方正智能审校 21 类 136 个词库是既成事实。词表是配角——**我们的位置在生产现场，知道哪一句是 AI 写的**。

**硬拦会不会误伤正常报道？**
会，所以硬拦只认「话术」「教程」这类操作指令式措辞。「打击传销」「破获制毒案」这些题材词一律走「要理由」，报道得了，也留了痕。**词表判不了意图**，真正的意图识别要靠模型判断层——这一点我们没有回避。

**我把数据改乱了怎么办？**
告诉管理员重新播种即可，一条命令的事（见 [operations.md](operations.md)）。

## 六、这一版明确不做

主动说明，比被问出来强：

- 不做内容采集，只粘贴 / 上传
- 不做多平台真实发布，按钮只演示状态变化
- 不做电子签章
- 不做权限配置界面（角色与权限是代码内固定组合）
- 不做图片 / 视频审核
- 模型判断层只标不拦，一律输出「待人工复核」，**不给自动终审结论**

## 七、附录 · 可直接粘贴的素材

> ⚠️ 以下全部为**模拟脱敏素材**。人名、地名、单位、数字均为虚构，不对应任何真实机构或个人。

**最省事的办法**：新建稿件页上有一个 **「填入示例通稿」** 按钮，一键填好标题、形态、方向和正文，不用打字。

下面这六份是给你想多试几种情况时用的。**照抄正文粘进「正文」框即可**，标题和两个下拉框按表头填。

| 你想看什么 | 用哪一份 |

| 一份正常的稿子怎么走完全程 | 素材 ①、③ |

### 素材 ① · 全市防汛抗旱工作会议召开

`政务通稿` · `时政` —— **仅留痕放行**，可以一路走到签发。

```
8月28日，全市防汛抗旱工作会议召开。会议分析当前汛情形势，部署下一阶段防汛抗旱重点工作。

会议要求，各县区各部门要严格落实责任，加密监测预报，确保安全度汛。
```

### 素材 ② · 全市文明城市创建工作推进会隆重召开

`政务通稿` · `文化教育` —— **仅留痕放行**。注意标题里就有「隆重召开」。

```
8月28日，全市文明城市创建工作推进会隆重召开。市文明办负责人亲自出席会议并发表重要讲话。

会议布署了下一阶段重点任务，全市已建成新时代文明实践中心 12 个，注册志愿者 8.6万人。

会议要求，各单位要一如继往抓好落实，确保创建工作取得实效。
```

> 这一份的**标题**里带着禁用词「隆重召开」，生成稿把它带了下去，预检会多标出一处。
> 正文里还埋了「布署」（应为部署）和「一如继往」（应为一如既往）——
> **这两处目前抓不到**，因为预检检的是**生成稿**，不是你贴进来的原稿。
> 这不是漏洞，是分工：原稿的错别字归人工一校，生成稿的才归机器。我们不假装这条线不存在。

### 想自己写一份？

三条就够：

1. **正文里放一个带单位的数字**（`3.2亿元`、`18 个`、`2.6万户`）——预检的一致性比对要拿它当锚点，没有数字就少一处可看的标注
2. **首句能直接当导语**——播报稿开头是「各位听众，」加你的第一句
3. **别在正文里写「诈骗话术」「制毒教程」这类词**，除非你就是想看硬拦
