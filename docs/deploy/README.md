配套脚本（源码在 `src/`，数据集定义在 `src/demo-dataset.ts`）：

```bash
npm run seed:demo                        # 建 4 个账号 + 7 篇稿件
npm run reset:demo -- --yes              # 清稿件，保留账号
npm run reset:demo -- --yes --accounts   # 连账号一起清
```

## 三条要点

**账号口令写在手册里**（默认 `gatekeeper-demo`）。这是有意的——对外试用要让人拿来就能登。
不想公开就设 `SEED_PASSWORD` 覆盖，并把手册里那一行改掉。

**播种走真实 API，不直接写库。** 稿件要经过准入、生成、预检、三审才会有留痕、句级来源和
AI 参与度。绕开路由插表，播出来的数据就不是系统真实产生的——夹具和真流程不一致，
它就失去了全部意义。

**清理脚本必须带 `--yes`。** 它删的是整库稿件连同留痕与审核记录，责任链删掉找不回来。

| 国道210线塌方抢通情况通报 | 待填选题依据 | 体验「要理由」那一档 |

改数据集改 `src/demo-dataset.ts`，改完实跑一次 `npm run seed:demo`
核对输出的那一行汇总——**词表或 mock 一变，那些数字就会变**。
