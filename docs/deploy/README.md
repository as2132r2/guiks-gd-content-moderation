配套脚本（源码在 `src/`，数据集定义在 `src/demo-dataset.ts`）：

```bash
npm run seed:demo                        # 建 5 个账号 + 15 篇稿件
npm run reset:demo -- --yes              # 清稿件，保留账号
npm run reset:demo -- --yes --accounts   # 连账号一起清
```

## 三条要点

**账号口令写在手册里**（默认 `gatekeeper-demo`）。这是有意的——对外试用要让人拿来就能登。
不想公开就设 `SEED_PASSWORD` 覆盖，并把手册里那一行改掉。

**播种走真实 API，不直接写库。** 稿件要经过准入、生成、预检、三审才会有留痕、句级来源和
AI 参与度。绕开路由插表，播出来的数据就不是系统真实产生的——夹具和真流程不一致，
它就失去了全部意义。

**清理脚本必须带 `--yes`。** 它删的是整库稿件连同留痕与审核记录，责任链删掉找不回来。

## 数据集里有什么

15 篇稿件，分两组。

**前 7 篇是教学样本**，**不是全部走到终态**——试用者需要有活可干：

| 稿件 | 停在 | 留给试用者做什么 |
| --- | --- | --- |
| 全市乡村振兴现场推进会召开 | 已发布 | 看完整追溯图谱与对照组 |
| 全市优化营商环境政策发布会举行 | 已发布 | 看退回重走两轮的留痕 |
| 全市中小学秋季开学工作部署会召开 | 预检完成 | **亲手改一句，看 AI 参与度跳变** |
| 全市城市更新项目集中开工 | 待复审 | **接手审批** |
| 国道210线塌方抢通情况通报 | 待填选题依据 | 体验「要理由」那一档 |
| 帮我写点东西 | 已拒绝 | 看硬拦：模型调用 0 次 |
| 写篇小说 | 已准入 | 看公器私用：只标不拦 |

**后 8 篇是本底数据**，`dayOffset` 铺在过去六天里，全部已发布。它们不参与教学，
只为一件事：**让监控看板不是一条竖线**——按日趋势要有多个点、生产量要有多个人、
报道方向要有分布。只有 7 篇同一天同一个人的稿子，那三栏都是空的。

本底稿件时间靠前且已发布，左栏按 `updated_at` 倒序，它们沉在底下，不会把教学样本挤掉。

改数据集改 `src/demo-dataset.ts`，改完实跑一次 `npm run seed:demo`
核对输出的那一行汇总——**词表或 mock 一变，那些数字就会变**。
