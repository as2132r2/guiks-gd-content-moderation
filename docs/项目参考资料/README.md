# 把关人 · 项目参考资料（广电方向）

> 从 `D:/project/广电内容/` 中筛选出的、与「把关人——县级融媒体中心稿件生产与监理平台」直接相关的文件。
> 来源目录仍保留全部 14 份原始文件，本目录只放项目需要的 6 份。

## 为什么是这 6 份

项目代码与文档（`docs/gatekeeper/`）明确引用这些文件作为**合规依据 / 词表来源 / 行业依据**：

| 文件 | 相关性 | 项目对应点 |
| --- | --- | --- |
| 《新闻信息报道中的禁用词和慎用词》2016-07 修订版.docx | **核心 · 词表来源** | 预检层「禁用词与慎用词」的直接数据源。plan.md 所称「新华社 102 条、五大类」即此文件；对应 requirements.md 轨道 B2（2.6 / 4.6 / 4.7 / 4.8），当前代码里是桩，需按此文件落地真实词表 |
| 关于印发《人工智能生成合成内容标识办法》的通知.docx | **核心 · 合规依据** | 网信办/工信部/公安部/广电总局四部门联合发布，2025-09-01 施行。AI 生成内容显式+隐式标识的法定要求，是「AI 参与度追溯」（§六、§九）的合规根基；对应 4.9–4.11 |
| 生成式人工智能服务管理暂行办法.docx | **核心 · 合规依据** | 要求服务提供者对违法输入采取处置措施（含暂停/终止服务），是「入口准入闸」（层 02）的法规依据 |
| 县级融媒体中心建设规范.pdf | **核心 · 行业标准** | 中共中央宣传部+国家广电总局 2019 年发布。定义了我们服务的对象（县级融媒体中心）的业务类型、总体架构、**内容审核**（6.6 多级审核）、融合发布、数据分析。作品说明的行业依据，评委问「这符合哪条标准」时用它背书 |
| 广电内容制作流程.docx | **有用 · 行业流程背景** | 三审三校、中央厨房、人机协同审核的行业实践综述。用于理解业务流程与写作品说明的叙事，非法规 |
| 广播电视安全播出管理规定.docx | **边界澄清 · 必读** | ⚠️ 项目措辞纪律明确：此规定管的是**技术性播出安全**（停播/信号/设备），**不管内容差错**，演示/文档中不可与三审三校混着讲。保留它用于在作品说明里主动划清这条边界 |
