## 怎么用

演示前把库重置成已知状态（D.4 / D.5 播种脚本尚未落地，暂时手工）：

```bash
docker compose down -v && docker compose up -d
```

然后按 [admission-cases.md](admission-cases.md) 的顺序建三份样例，再建主通稿走全链路。

## 素材改动纪律

**这两份素材不是随便写的文字，是按规则实测调出来的。** 改之前先读
[source-notice.md](source-notice.md) 的「四条硬要求」——第一个带单位的数字必须是金额、
不能命中准入词、首句要能当导语、领导职务写法要正确。任一条破了，对应的镜头就演不出来。

改完**必须实跑核对**实测结果表里的数字，那些数字是口播里要报出来的。
