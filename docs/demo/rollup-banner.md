# 展台易拉宝 80×200cm

> ⚠️ 同本目录其余素材一样，画面上出现的通稿数字为**模拟 / 脱敏样例**。
> 易拉宝上已印明这一点，见下方「数字与出处」。

现场展位用的一张易拉宝，同时讲清三件事：**项目是什么**、**为什么别人做不出来**、**谁做的**。
视觉沿用产品自己的皮肤（`#0E1512` 底 / `#33D6A2` 主色 / 宋体标题 / 等宽标签），
评委在展位看到的和 [script.md](script.md) 里演示的是同一套东西。

## 文件

| 文件 | 用途 |
| --- | --- |
| [rollup-banner.html](rollup-banner.html) | **印刷源，1:1 制版。** 自包含单文件，无外部依赖，浏览器直接打开即所见即所得 |
| 画布版（可视化编辑） | <https://claude.ai/code/artifact/b9f4f52e-877f-4861-a825-91b52247ac17>，另含两版方向草稿 |

改文案改 `rollup-banner.html` 一处即可，它就是排版本身。

## 规格

| 项 | 值 |
| --- | --- |
| 成品尺寸 | 80 × 200 cm（易拉宝标准幅面） |
| 制版尺寸 | **3024 × 7559 px @ 96 px/英寸**，即 1:1 |
| 版心 | 左右各留白 190 px（约 5 cm） |
| 底部安全区 | 最下 ~18 cm 会被支架和视线遮挡，只放了出品方与二维码 |
| 主标题位置 | 离地约 172–185 cm，站立视线正上方 |
| 正文最小字号 | 38 px（约 1 cm），1.5–2 m 距离可读 |

版面实测：内容止于 6597 px，页脚贴底 7559 px，`scrollHeight` 等于版高，**无溢出、无裁切**。
改动后请照下面的命令复测——`box-sizing` 之类的疏漏会让右侧几百像素被静默裁掉。

## 出图与复测

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --hide-scrollbars --window-size=3024,7559 --virtual-time-budget=5000 --screenshot=rollup.png "file://$PWD/docs/demo/rollup-banner.html"
```

得到 3024×7559 的 PNG（约 1.3 MB），可直接交喷绘店。**生成物不入库。**
要 PDF 就用浏览器打印，页面已写好 `@page { size: 80cm 200cm; margin: 0 }`。

> 喷绘店若问分辨率：易拉宝观看距离 1.5 m 以上，96 dpi 足够；要求更高就把
> `--window-size` 和版心尺寸按倍数放大重出，版面是纯矢量与文字，放大不失真。
